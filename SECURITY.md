# Security

KodaMemo is an alpha intended for local, single-owner development. Do not expose it directly to the public internet.

Do not open a public issue containing credentials, recordings, exploitable details or personal data. If private vulnerability reporting is enabled on the GitHub repository, use its Security tab. Otherwise request a private contact route without publishing the vulnerability itself.

No supported production release or security response-time guarantee is currently offered. See docs/ARCHITECTURE.md for the present security boundaries.
